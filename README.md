# 📚 Bookstore API

A RESTful API for a Bookstore application built with **Node.js**, **Express**, and **MongoDB**. This API supports **user authentication** (JWT-based) and full **CRUD operations** for managing books. It also includes **API documentation using Swagger**.

---

## 🚀 Features

- ✅ **User Authentication**
  - Sign Up
  - Login (JWT Token)
  - Protected Routes for Book Management

- 📖 **Books CRUD**
  - Create Book
  - Read All Books / Single Book
  - Update Book
  - Delete Book

- 🧾 **Swagger UI Documentation**
- 📡 RESTful Routes
- 🔐 Secure Passwords (with bcrypt)
- 🌐 MongoDB for persistent data

---

## 🧰 Tech Stack

| Technology     | Purpose                            |
|----------------|------------------------------------|
| Node.js        | Runtime environment                |
| Express.js     | Server & routing framework         |
| MongoDB        | NoSQL database                     |
| Mongoose       | MongoDB ODM for schema models      |
| JWT            | Authentication (stateless)         |
| bcryptjs       | Password hashing                   |
| Swagger        | API documentation                  |
| dotenv         | Environment variable management    |
